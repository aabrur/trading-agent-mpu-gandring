# Jev sidecar + REA toolkit implementation plan

Architecture: Jev is an optional Decisions API sidecar. REA is an optional developer toolkit. Six agents keep debate. Deterministic code keeps risk and execution.

## Phases

1. P0 evidence integrity (news publishedAt vs observedAt, reported vs verified veto, whale nulls).
2. P1 OpenRouter Decisions adapter + BYOK (`JEV_*`, reuse `OPENROUTER_API_KEY`).
3. P2 pre-analysis + post-verdict questions, SHADOW logs only, ASSIST enriches PAPER/TESTNET unless `JEV_ALLOW_LIVE=yes`.
4. P3 Setup UI + Desk Ops monitor.
5. P4 REA developer notes. No runtime dependency.
6. P5 focused tests, typecheck, build, phase commits.

TypeSafe Direct is deferred until a real auth contract is implemented.

Jev never places, cancels, or resizes orders and never loosens a hard guard.
